Ledger — a fast, dependency-free make.fun frontend. Live bounty board with live pots, entry fees, time left and entries; a bounty page with rules and rewards; its leaderboard; and any account's public profile. One cached API request per view, no framework, no build step, no sign-in.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
